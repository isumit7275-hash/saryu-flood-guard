# Saryu Flood Guard - Saryu Rakshak

Saryu River Flood Early Warning System using NASA SAR Satellite Data
NASA Space Apps Challenge 2026 - Lucknow

## Problem
Har saal Saryu nadi me baadh se Tarabganj aur Ayodhya ke gaon doob jaate hai. Logo ko pehle pata hi nahi chalta.

## Solution
Hamara project NASA ke SAR Satellite Data ka use karke baadh se pehle warning deta hai.
Early Warning System - Problem hone ke baad batana aasan hai, pehle batana hi asli kaam hai.
